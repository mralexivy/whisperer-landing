Is voice coding faster than typing? Sometimes, and the answer depends almost entirely on what you're writing. For prompts, comments and messages, voice usually wins by a wide margin. For raw syntax full of brackets and operators, typing wins. With AI coding agents, more of a developer's day falls into the first group.

## The raw numbers

| | Typing | Speaking |
|---|---|---|
| Commonly quoted average | about 40 wpm | about 130 to 150 wpm (conversation) |
| Experienced | 60 to 80+ wpm | similar; speech rate varies less than typing |

These are general figures, not measurements of you. Dictation is usually slower than conversation, because you pause to think. It's still well ahead of typing for most people. Whisperer's Statistics page shows your own dictation words per minute, so you can check.

## It depends on the task

The tables below describe direction, not stopwatch results. Your margins will vary.

### Prompts to AI coding agents: voice wins

Prompts for Cursor, Claude Code, Codex or Copilot are plain language, and longer prompts tend to get better results. Speaking makes the long version cost about the same as the short one.

| Task | Faster with |
|---|---|
| One-line inline edit prompt | Roughly even |
| A paragraph describing a refactor | Voice |
| A multi-paragraph feature request | Voice, clearly |

### Comments, docs and PR text: voice wins

Prose, with few symbols. Accuracy is high, especially once your project's names are in the [personal dictionary](/features/personal-dictionary).

| Task | Faster with |
|---|---|
| Inline comment | Voice |
| Docstring | Voice |
| README section or PR description | Voice, clearly |

### Slack and email: voice wins

| Task | Faster with |
|---|---|
| Quick chat reply | Voice |
| Email reply | Voice |
| Long email | Voice, clearly |

### Writing syntax by hand: typing wins

Whisperer writes what you say as text. It has no spoken symbol or casing commands, so code syntax goes on the keyboard. Even tools that do have them are slow for dense expressions, because every bracket and dot has to be spoken.

| Task | Faster with |
|---|---|
| Expression with brackets and operators | Typing |
| New variable or function name | Typing |
| A whole function | Ask the agent, by voice |

## What to use for what

| Task | Input |
|---|---|
| Agent prompts and review feedback | Voice |
| Comments, docs, PR descriptions | Voice |
| Messages and email | Voice |
| Syntax, renames, small edits | Keyboard |
| Navigation and selection | Keyboard |

## AI coding changes the math

Before coding agents, most of a developer's typing was syntax, which favours the keyboard. Now a large part is describing changes in English, which favours voice.

| Typing code yourself | Working with an agent |
|---|---|
| Mostly symbols | Mostly prose |
| Keyboard is faster | Voice is faster |
| Speed limited by typing | Speed limited by how clearly you explain |

If your day is mostly prompting, voice can make a real difference. If you still write most code by hand, the gain is mainly in messages and docs.

## How to measure your own gain

1. Use voice for a week for prompts, messages and docs only.
2. Check Whisperer's **Statistics** page for words dictated and your dictation words per minute.
3. Compare with your typing speed from any online typing test.

That gives you a real number instead of an estimate.
