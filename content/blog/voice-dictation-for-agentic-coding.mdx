In agentic coding, you spend more time telling an AI what to build than writing code yourself. Claude Code, Codex, Cursor and Windsurf do the implementation; you describe, redirect and review. Most of your input is now plain language, and plain language is what voice is good at.

<Callout type="info">
Typing speed used to be a coding skill. With agents, what matters is how quickly and clearly you can explain a change. Conversational speech is commonly around 130 to 150 words per minute, well above most people's typing.
</Callout>

## Why voice works here

<FeatureGrid>
<FeatureCard title="Speed" icon="zap">
A feature description that takes a couple of minutes to type takes well under a minute to say. Agents get dozens of these a day.
</FeatureCard>
<FeatureCard title="Better prompts" icon="file-text">
Typed prompts get terse. Spoken ones include the context, constraints and edge cases an agent needs.
</FeatureCard>
<FeatureCard title="Less fatigue" icon="shield">
Long prompting sessions are a lot of typing. Speaking moves most of it off your hands.
</FeatureCard>
<FeatureCard title="Review is conversation" icon="eye">
"Good, but make the error handling more specific" is easier to say than to type.
</FeatureCard>
</FeatureGrid>

## The voice and agent loop

Each step is the same action in Whisperer: hold Fn, speak, release, press ⌘V, send. Whisperer copies the text and shows a **Copied ⌘V** toast; it never types or presses Return for you.

## Setting up

<StepList>
<Step num="1" title="Install Whisperer">
From the Mac App Store, $2.99. Apple Silicon and macOS 26 Tahoe.
</Step>
<Step num="2" title="Add your vocabulary">
Library, service and product names go in the [personal dictionary](/features/personal-dictionary), so "Zod" and "PostgreSQL" don't come out as something else.
</Step>
<Step num="3" title="Use a clear mic">
Built-in is fine in a quiet room. A headset helps when you're giving long, detailed instructions.
</Step>
<Step num="4" title="Watch the live preview">
Words appear as you speak, so you can catch a misheard name before you paste.
</Step>
</StepList>

There's nothing to set per tool. Whisperer writes what you say as plain text, which is exactly what agents take. It doesn't do spoken symbol or casing commands; the agent writes the syntax.

## Give agents what you've said, not just what you type

This is the part that changed in Whisperer 2.0. With Pro, Whisperer can run a local **MCP server**, so your agent can read your meetings and dictations directly:

- `search_meetings` and `get_meeting_transcript` let it find the call where a feature was discussed
- `search_transcriptions` and `get_transcription` let it read a long dictation you made earlier, such as a spoken bug report or design notes
- `add_meeting_note` lets it write a summary back

One-click setup covers Claude Code, Codex, Cursor, VS Code and Windsurf, among others. The server is off by default and listens only on your Mac. A prompt like "find what we decided about rate limits in Monday's call and implement it" then works from the real conversation. See the [MCP page](/mcp) and [meeting notes](/meetings).
